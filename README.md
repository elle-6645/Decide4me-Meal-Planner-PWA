# Decide4me Meal & Drink Planner — PWA

This folder is the **repository root** for `Decide4me-Meal-Planner-PWA`.

## GitHub upload

Upload the **contents of this folder**, not the ZIP and not an outer parent directory.

The repository root should contain `index.html`, `manifest.webmanifest`, `sw.js`, and `icons/`.

## PWA

The app includes:
- Web App Manifest
- Service worker registration
- Offline app-shell caching
- Standalone display mode
- Android/iOS web-app metadata

After GitHub Pages is enabled, open the HTTPS Pages URL in a supported browser and use the browser's **Add to Home Screen / Install App** option.

## Android

Once the PWA is live over HTTPS, it can be packaged with PWABuilder/Trusted Web Activity tooling.
