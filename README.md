# Decide4me Meal & Drink Planner — PWA

This is the clean repository root for the updated Decide4me app.

## Files
- `index.html` — the actual Decide4me application
- `manifest.webmanifest` — PWA manifest
- `sw.js` — offline service worker
- `icons/` — PWA icons

## GitHub Pages
Use **Settings → Pages → Deploy from a branch → main → / (root)**.

The resulting site should be:
`https://elle-6645.github.io/Decide4me-Meal-Planner-PWA/`
